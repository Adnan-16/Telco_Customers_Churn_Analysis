# Telco_Customers_Churn_Analysis
End-to-end Telco customers churn analysis utilizing python , SQL and Power BI for interactive executive dashboards.

## 📌 Overview
This project analyzes Telco customers churn using **Python, MySQL, and Power BI**. It focuses on identifying churn patterns, high-risk customers, and key factors affecting customer retention.

## 🛠️ Tools Used
- Python (Pandas, NumPy)
- MySQL
- Power BI

## 📊 Key Insights
- Overall Churn Rate: **26.54%**
- Month-to-Month contracts have the highest churn.
- Fiber Optic customers show the highest churn rate.
- Mailed Check users have the highest churn among payment methods.
- Customers with low tenure and high monthly charges are at higher risk of churning.

## 📈 Analysis Performed
- Overall Churn Rate
- Churn by Contract Type
- Churn by Payment Method
- Churn by Internet Type
- First-Year Churn Analysis
- High-Risk Customer Identification

## 💡 Business Recommendations
- Promote long-term contracts.
- Offer targeted retention campaigns for high-risk customers.
